# 🧁 Sistema de Vendas - Loja de Cupcakes Gourmet

Projeto desenvolvido para a disciplina de **Projeto Integrador Transdisciplinar em Engenharia de Software II (PIT II)** da Universidade Cruzeiro do Sul Virtual.

## 🚀 Funcionalidades
- Vitrine virtual de cupcakes com preços e descrições.
- Carrinho de compras interativo com cálculo automático do valor total.
- Simulação de checkout e envio de pedidos.
- Estruturação em arquitetura **MVC** (Model-View-Controller).

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3 e JavaScript
- **Back-end:** Python (Flask)
- **Banco de Dados:** MySQL / Scripts SQL inclusos
